# Multi-Brand Marketing Campaign Performance Analysis and Prediction

## Project Overview

This project focuses on analyzing and predicting the performance of marketing campaigns across multiple brands using Python, SQL, and Machine Learning.

The project takes raw marketing campaign data, performs data cleaning and preprocessing, feature engineering, exploratory data analysis, machine learning, and presents the results through an interactive Streamlit dashboard.

The project provides two major prediction capabilities:

- Revenue Prediction using Regression
- Profit/Loss Prediction using Classification

## Problem Statement

Marketing teams generate large amounts of campaign data containing impressions, clicks, leads, conversions, acquisition costs, revenue, ROI, and marketing channels.

When this data is stored in raw formats such as CSV files, it becomes difficult to identify high-performing campaigns, effective marketing channels, profitable campaigns, and relationships between campaign features.

This project addresses these challenges by transforming raw campaign data into meaningful insights and machine learning-based predictions.

## Objectives

- Clean and preprocess raw marketing campaign data
- Handle missing values and duplicate records
- Perform data transformation and type conversion
- Validate and correct ROI values where required
- Apply multi-label encoding to marketing channels
- Create a Profit_Flag feature for Profit/Loss classification
- Perform Exploratory Data Analysis (EDA)
- Analyse campaign, brand, and channel performance
- Build regression models for Revenue prediction
- Build classification models for Profit/Loss prediction
- Evaluate machine learning models using appropriate metrics
- Develop an interactive Streamlit dashboard

## Feature Engineering

### Profit Flag

A new Profit_Flag feature is created based on ROI.

- Positive ROI → Profit
- Non-positive ROI → Loss

This feature is used as the target for the Profit/Loss classification task.

### Multi-Label Encoding

A campaign may use multiple marketing channels in the Channel_Used feature.

For example:

Facebook, Instagram, Google

The channels are transformed into numerical features such as:

- Channel_Facebook
- Channel_Instagram
- Channel_Google

This allows machine learning models to process multiple channels associated with a single campaign.

## Machine Learning

### Revenue Prediction

Revenue is a continuous numerical variable, so Regression is used for prediction.

Regression models include:

- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor

The models learn patterns from historical campaign data and predict the expected revenue for a new campaign.

ROI is excluded from the Revenue prediction features where it could cause data leakage because ROI is related to Revenue and Acquisition Cost.

### Profit/Loss Prediction

Profit/Loss is a categorical output, so Classification is used.

Classification models include:

- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier

The models predict whether a campaign is likely to be:

- Profit
- Loss

## Model Evaluation

### Regression Metrics

The regression models are evaluated using:

- MAE - Mean Absolute Error
- MSE - Mean Squared Error
- RMSE - Root Mean Squared Error
- R² - R-squared

### Classification Metrics

The classification models are evaluated using:

- Accuracy
- Precision
- Recall
- F1-Score

Model performance is compared to identify suitable models for the prediction tasks.
